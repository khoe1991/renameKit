# 轻改名 RenameKit

SwiftUI 原生 macOS 工具：用文件创建时间批量重命名，保留扩展名，重名时才追加数字或字母。

## 构建并打开

需要安装 Xcode Command Line Tools。在项目目录执行：

```sh
./build.sh
open build/RenameKit.app
```

更新后先退出已打开的旧版，再打开新版。当前构建适用于 Apple Silicon，部署目标 macOS 13.0。

## 使用

1. 添加文件 / 文件夹，或拖入文件。
2. 唯一命名方案是“文件创建时间（日期 时分秒）”。
3. 直接编辑左侧命名规则；左侧“规则验证”显示实时结果与错误原因。
4. 预览默认显示文件目录、原始名称、修改后名称及原始创建时间。
5. 右上角“文件信息”可勾选创建时间、修改时间、访问时间、大小、类型和扩展名，按需增加或隐藏列。
6. 点击“重命名”后，在任务窗口逐行核对原始名称、新名称及目录，进入确认窗口后自动调用文件名二次校验模块，按本次预览规则重新读取文件信息并校验完整清单；校验中或有不一致/无法校验项时，“确认并开始”不可点击。全部通过后方可确认并逐个执行。执行前的“取消”只关闭窗口，不修改文件。

左侧没有滚动配置、命名片段组合、自定义方案库、时区或排序选项。按文件创建时间从早到晚处理，同一创建时间按原名称排序。使用系统时区和 Finder 中的文件创建时间。

默认规则 `yyyyMMdd_HHmmss` 生成 `20261017_153030.MOV`。

## 可编辑规则

| 规则 | 示例结果 |
| --- | --- |
| `yyyyMMdd_HHmmss` | `20261017_153030` |
| `yyyy-mm-dd` 或 `yyyy-MM-dd` | `2026-10-17` |
| `yyyy-MM-dd_HH-mm-ss` | `2026-10-17_15-30-30` |
| `yyyymmmdd` 或 `yyyyMMMdd` | `2026Oct17` |
| `yyyy年MM月dd日_HHmmss` | `2026年10月17日_153030` |

常用符号：`yyyy` 四位年、`MM` 两位月、`dd` 两位日、`HH` 24 小时制的小时、`mm` 分钟、`ss` 秒、`SSS` 毫秒。支持 `yy` 两位年，`MMM` 英文月份简称和 `MMMM` 英文月份全称。

日期部分也接受小写 `m/mm/mmm/mmmm` 表示月份；`HH` 后的小写 `m/mm` 表示分钟。`MM` 始终表示月份。推荐使用 `yyyyMMdd_HHmmss`，使月份和分钟清楚区分。

`-`、`_`、`.`、空格、中文可直接作为分隔文字。固定英文需用单引号包住，例如 `'IMG_'yyyyMMdd`。引号内部的单引号用两个单引号表示。

不支持的符号、错误位数、重复字段、未闭合引号、路径字符 `/`、冒号 `:`、换行和过长规则都会显示错误。验证未通过时不能执行重命名。示例固定使用 2026-10-17 15:30:30；文件预览使用每个文件自己的实际创建时间。

规则、冲突策略和文件信息列选择自动保存到 `~/Library/Application Support/RenameKit/settings.json`。旧版多方案文件不再载入，避免已删除的复杂方案重新出现。

## 文件信息和确认清单

文件信息列只读取文件系统属性，不读取后再写回内容，也不会转换文件格式。创建时间默认显示为 `yyyy-MM-dd HH:mm:ss`，与 Finder 的文件创建时间相同来源；可选信息的显示位置在前三个固定列之后。列宽可拖动调整，列多时可横向滚动，悬停可查看完整内容。列选择会在重新打开后恢复，“恢复默认列”只显示创建时间。

确认窗只列出本次实际修改的文件，提供原始名称、修改后名称、状态及文件目录，名称不变的文件会跳过。确认清单固定在打开弹窗时的计划；确认后再检查目录，若目标名称发生变化，会拒绝执行并要求重新预览，避免改成用户没有确认过的新名称。

## 逐文件执行和控制

最终确认窗口的“确认并开始”按钮旁可选择执行间隔：0、100、200、500 毫秒，默认 200 毫秒，自动保存。等待发生在两个文件之间，第一项立即开始，最后一项完成后不再等待；确认窗口显示本次使用的间隔。暂停、停止或回滚会立即打断间隔等待。回滚仍逐个执行，不额外等待。

执行后任务窗口保持打开，每行显示“待执行 / 执行中 / 成功 / 失败”，成功项显示绿色勾。顶部显示成功、失败和已恢复数量。失败时自动暂停，具体原因显示在窗口上方及对应行提示中；排除原因后可“重试并继续”。

| 按钮 | 行为 |
| --- | --- |
| 暂停 / 继续 | 在当前文件结束后暂停，从下一个未完成文件继续；失败后重试当前失败项 |
| 停止，保留已完成 | 终止任务，成功文件保留新名，未执行文件保持原名，不自动回滚 |
| 停止并回滚 | 终止后逐个恢复本次已修改的名称，逐行显示回滚结果 |
| 回滚本次 | 完成或停止后，在当前任务窗口回滚本次成功项 |
| 重试回滚 | 排除占用等原因后，只重试尚未恢复的项目 |

暂停、停止和回滚请求均在当前文件的完整操作之后生效。每个文件直接从原名改成目标名一次；预览会避开同批其他文件的原名，因此停止后不会遗留未执行文件的临时名称或名称互换依赖。

回滚不会覆盖后来创建的同名文件；某一项恢复失败时，会继续恢复其他项，并保留失败记录。任务窗口运行中或暂停时不能直接关闭，需先继续、停止或回滚。执行前可取消，结束后可关闭。结束状态的“关闭”是右侧主按钮，支持回车；“回滚本次…”位于左侧，点击后需再次确认，取消确认会保留当前名称。

停止后的当前任务不再继续执行；如需继续，应关闭任务窗、刷新预览并重新确认剩余操作。停止后仍可以从主窗口“撤销 / 恢复”撤销已完成的部分。

## 冲突处理

默认“加字母”，也可选择“提示”或“加数字”。只有目标名称冲突的文件才追加后缀：

```text
20261017_153030.MOV
20261017_153030_a.MOV
20261017_153031.MOV
```

已有 `_a` 时跳过，继续尝试 `_b`、`_c`。超过 z 后继续 aa、ab。数字后缀从 `_1` 开始。

每个文件夹独立检查已有文件和本批目标名称。拖入文件夹时默认只添加醒目的文件夹分组，不修改文件夹名。每个分组可单独勾选“导入内部文件”，后台只读取本层普通文件，不递归子文件夹，并跳过隐藏文件、应用包和符号链接。取消勾选或移出分组会移出仅由该分组导入的文件，单独添加的文件保留；选中预览中的一行后，列表底部显示该文件的操作栏，可直接“移出列表”或“定位到文件夹”，无需右键；列表中移除或清空不会删除磁盘文件。

预览提供“全部 / 待修改 / 名称不变 / 需处理”筛选及各类数量，每行显示明确状态；名称相同的文件显示“名称不变 · 跳过”，确认执行时也会说明跳过数量。筛选只影响显示，不改变执行范围，最终仅对完整预览中的待修改项执行操作。

窗口默认约 1000×640，支持拖小至 760×520。侧栏右边缘居中的左箭头将侧栏收进左边缘，边缘在同一高度保留右箭头，悬停时高亮，点击后侧栏向右展开。宽度不足 960 时侧栏默认收起，再展开时覆盖在预览左侧，避免挤压表格。顶部“添加文件 / 文件夹”“刷新预览”“清空列表”始终直接显示，不合并到菜单。预览表格保留横向滚动，文件夹区域按窗口高度限制展示行数；确认和校验弹窗会跟随主窗口尺寸调整。

## 文件名二次校验

预览右上角“校验”打开只读窗口。左侧为冻结的预览名称、校验结果及按校验规则应生成的名称，右侧为最新文件信息，默认显示创建时间，也可切换其他列。可选择预设日期规则或自行调整，并筛选“不一致 / 无法校验”。校验规则仅用于比对，不改变主界面规则或预览。

校验重新读取本地或 SMB 文件属性，并按本批冲突策略计算完整名称，包括仅冲突项的字母或数字后缀。文件信息变化、名称不匹配、文件丢失或规则错误会明确提示。校验不改名、不写文件内容。它提供直观复核与最新信息比对，日期格式仍使用同一解析器，不能保证发现生成器自身的所有错误。

## 撤销和恢复

通过“帮助 → 查看操作记录”可打开历史日志目录。主窗口可撤销最近一批已执行操作。每个任务另存详细历史日志，新批次不会删除旧日志。

- 每个文件直接从原名改为目标名一次，回滚也直接恢复原名。新任务不使用临时文件名。
- 优先使用系统禁止覆盖重命名；SMB 不支持该标志时使用 macOS FileManager 的同目录移动接口，目标存在时拒绝移动。只允许同目录操作，并禁止复制回调。
- 改名前将恢复意图写入 `~/Library/Application Support/RenameKit/last-operation.json`，改名后立即更新。异常发生在改名成功与状态保存之间时，恢复按记录中的原始完整路径与目标完整路径处理，不依赖文件编号或内容哈希。
- 每个任务在 `~/Library/Application Support/RenameKit/history/<任务ID>.json` 保留可读日志：完整文件清单、命名配置、原路径、目标路径、设备和 inode、原始大小/创建/修改时间、每次执行和回滚的意图、结果、错误和时间。失败、重试及回滚后仍保留日志。
- 失败时暂停，不自动回滚之前成功的文件。恢复遇到原名被占用或记录路径下找不到文件时停止并保留记录。
- 兼容旧版本遗留的临时名称和恢复记录；请保留旧记录相关文件，直至恢复完成。

## 构建和验证

需要 Apple Command Line Tools 或 Xcode，无第三方依赖：

```sh
./build.sh
./verify.sh
```

本机 ad-hoc 签名；正式对外分发需 Developer ID 签名及 Apple 公证。

源码：

- `Source/RuleConfiguration.swift`：共享规则解析、校验、日期格式化和简洁设置。
- `Source/RenameEngine.swift`：创建时间计划、确认清单校验、冲突检测和历史恢复。
- `Source/SequentialRenameSession.swift`：逐文件串行执行、检查点与单项回滚。
- `Source/RenameTask.swift`：暂停、继续、停止、失败重试及回滚状态机。
- `Source/RenameTaskSheet.swift`：逐行进度和任务控制窗口。
- `Source/FileInformation.swift`：只读文件属性快照和显示字段。
- `Source/FilePreviewTable.swift`：支持动态显示列及横向滚动的原生表格（兼容 macOS 13）。
- `Source/RenameApp.swift`：原生界面和操作状态。
- `Scripts/verify.swift`：隔离临时文件中的规则与重命名验证。
